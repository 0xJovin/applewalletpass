# Security Policy

## Supported Versions

Currently, only the latest version of the library receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| < 1.1.x | :x:                |

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability within this project, please send an e-mail to the maintainer via GitHub or open a private issue if available.

Please do not report security vulnerabilities through public GitHub issues.

### Response Time

We will acknowledge receipt of your vulnerability report within 48 hours and strive to send a follow-up response within 72 hours detailing the next steps in the investigation and remediation process.
